# AI Commons Directory

This skill provides a curated directory of 100 high-value AI systems, categorized by their primary function. It serves as a reference for selecting specialized AI tools beyond general-purpose models.

## How to Use This Skill

When faced with a task that requires specialized domain expertise or specific AI capabilities, consult the directory to find the most appropriate system.

1.  **Identify the Category**: Determine which of the 12 categories the task falls under (e.g., Medical, Coding, Audio).
2.  **Consult the Reference**: Read the [ai_systems_directory.md](references/ai_systems_directory.md) file to see the full list of systems in that category.
3.  **Select the Best Tool**: Choose the system that best matches the specific requirements (e.g., "privacy-focused", "open-source", "real-time").
