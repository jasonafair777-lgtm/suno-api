# Research Workflow & Citation Management

## Literature Review Process

### Step 1: Establish Research Scope
- Define primary research question
- Identify key domains and disciplines
- List 5-10 core concepts to search

### Step 2: Conduct Multi-Layer Search

**Layer 1: Broad Synthesis (Perplexity + Consensus)**
- Use Perplexity for real-time, comprehensive overviews
- Use Consensus for meta-analysis of peer-reviewed findings
- Capture: Overview, key findings, consensus areas, controversies

**Layer 2: Academic Depth (Semantic Scholar + Scite)**
- Use Semantic Scholar for citation networks and influential papers
- Use Scite for paper validation (supporting vs. contradicting citations)
- Capture: Citation count, influence, methodological rigor

**Layer 3: Specialized Sources (Domain-Specific Tools)**
- JSTOR, PubMed, Google Scholar, Scopus, Web of Science
- ArXiv, Dimensions AI, Lens.org
- Capture: Domain-specific findings, emerging research, preprints

### Step 3: Knowledge Mapping

**Using Research Rabbit + Connected Papers:**
1. Enter key papers into Research Rabbit
2. Generate citation network visualization
3. Identify clusters and relationships
4. Locate seminal works and emerging research
5. Export network for documentation

### Step 4: Fact-Checking & Validation

**For Each Major Claim:**
1. Search Scite for supporting/contradicting citations
2. Check Consensus for meta-analysis agreement
3. Verify methodology and sample size
4. Note confidence level (high/medium/low)
5. Flag speculative vs. proven findings

## Citation Management

### Using Zotero + BibGuru

**Workflow:**
1. Create Zotero collection for project
2. Add papers from Semantic Scholar, Scite, Google Scholar
3. Tag with: domain, methodology, confidence level
4. Add notes: key findings, quotes, limitations
5. Export bibliography in required format (APA, Chicago, MLA)

### Citation Best Practices

- **In-text citations:** Use author-date format (Smith et al., 2023)
- **Controversial claims:** Cite multiple sources, note disagreement
- **Speculative content:** Label as "hypothetical" or "proposed"
- **Recent findings:** Include publication date and journal impact
- **Methodology:** Note sample size, study design, limitations

## Academic Rigor Checklist

- [ ] All factual claims have citations
- [ ] Controversial claims cite multiple sources
- [ ] Speculative content is clearly labeled
- [ ] Methodology and limitations are noted
- [ ] Recent research is included (last 5 years)
- [ ] Seminal works are referenced
- [ ] No circular citations or self-referential claims
- [ ] Bibliography is complete and formatted correctly

## Handling Conflicting Research

**When sources disagree:**
1. Note the disagreement explicitly
2. Cite both perspectives
3. Explain methodological differences
4. Indicate which finding is more widely accepted
5. Suggest reasons for the discrepancy

**Example:**
"While Smith (2020) found X, Johnson (2021) demonstrated Y. This discrepancy may be due to differences in sample size (n=50 vs. n=500) and methodology (observational vs. experimental). The larger, controlled study by Johnson is considered more definitive."

## Integration with Writing

**In Manuscript:**
1. Use citations to support scientific claims
2. Use citations to establish credibility
3. Use citations to acknowledge prior work
4. Use citations to distinguish your contribution

**Citation Density:**
- Scientific sections: 1-2 citations per paragraph
- Lyrical sections: Minimal citations (focus on prose)
- Methods: Heavy citations (establish rigor)
- Results: Citations for context, not findings
- Discussion: Heavy citations (compare to literature)
